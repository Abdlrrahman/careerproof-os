# Changelog — CareerProof OS

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-25
### Added
- **Public Recruiter Experience**:
  - Professional hero with 60s, 3m, and 10m review modes.
  - 10 Dynamic Role Lenses for contextual reorganization of skills and proof.
  - Interactive SVG Proof Graph with accessible Table/List fallback.
  - Deterministic Evidence-Based Skill Engine (Familiar, Applied, Proven, Advanced, Leadership).
  - Production case studies and in-development concept architectures.
  - Non-linear professional experience timeline.
  - Verified quantifiable metrics and credentials showcase.
  - Role-specific Résumé Center (ATS single-column, visual, JSON Resume, print/PDF).
  - In-browser Job-Fit Analyzer with match scoring and evidence citations.
  - Grounded "Ask My Portfolio" AI Assistant with prompt injection protections.
- **Private Job Command Center (`/dashboard`)**:
  - Multi-format Opportunity Inbox (Paste JD, URL, CSV, Manual).
  - Multi-factor Opportunity Scoring.
  - 11-Stage Kanban & Table Application Pipeline.
  - Application Studio for grounded tailored document generation.
  - Interview Room with STAR story generation and company research checklists.
  - Job search conversion analytics and performance metrics.
  - Full Admin CMS for content, translations, site settings, and audit logs.
- **Bilingual & Accessibility Architecture**:
  - Full English LTR (`/`) and Arabic RTL (`/ar`) localization.
  - WCAG 2.2 AA compliant typography, contrast, keyboard focus, and reduced-motion support.
- **Data & Testing Infrastructure**:
  - Dual-mode data persistence (Zero-config embedded store + Supabase PostgreSQL).
  - Vitest unit & integration test suites.
  - Complete technical documentation and deployment blueprints.
