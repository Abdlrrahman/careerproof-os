## 1. Executive Overview

**CareerProof OS** is not a generic personal portfolio or résumé site. It is an editorial, evidence-driven career operating system designed to establish **Abdlrrahman Shibani's** authoritative profile for high-impact international remote roles across:

* **AI & Machine Learning Engineering** (Predictive pipelines, GeoBERT domain models, spatial GIS analytics, grounded RAG)
* **Full-Stack & Backend Systems Architecture** (High-throughput APIs, PostgreSQL/PostGIS, strict TypeScript, Docker)
* **Technical Leadership & Engineering Management** (Directing multidisciplinary squads up to 15 engineers)
* **Digital Transformation & Institutional Modernization** (Municipal portals, ERP systems, international donor programs)
* **Domain Consulting** (Energy/Petroleum analytics, Telecom intelligence, Banking & Fintech)

The platform answers critical recruiter questions within **60 seconds**:
1. **Who is Abdlrrahman?** Founder and Senior Engineering Lead with 6+ years shipping production software and leading distributed teams.
2. **What roles is he qualified for?** 10 dynamic role lenses tailored with real evidence.
3. **How many skills has he demonstrated?** Dynamically calculated from published records (never hard-coded).
4. **Which skills are supported by evidence?** Deterministic scoring with attached codebases, systems, and accredited certificates.
5. **What measurable outcomes has he delivered?** 40% reduction in manual data processing, 150+ personnel trained, 200k+ citizens reached.
6. **How closely does he match my open position?** In-browser Job-Fit Analyzer calculating match scores against any raw JD.
7. **How can I interview or hire him?** Instant Calendly booking, direct LinkedIn, and email inquiry channels.

## 2. Product Features

### 2.1 Public Recruiter Experience
* **60s / 3m / 10m Adaptive Recruiter Modes**: Tailor content density and depth to your schedule.
* **10 Dynamic Role Lenses**: Reorganize skills and case studies for targeted review without fabricating experience.
* **Interactive Proof Graph**: Node-link topology connecting skills, projects, roles, and credentials with an accessible HTML table fallback.
* **Deterministic Evidence-Based Skill Engine**: Mathematical proficiency calculation (`Familiar`, `Applied`, `Proven`, `Advanced`, `Leadership`) based on tangible proof items.
* **Grounded "Ask My Portfolio" AI Assistant**: RAG assistant answering recruiter queries with verified citations and prompt injection defense.
* **Résumé Center**: ATS single-column machine-readable version, visual executive layout, JSON Resume export, and PDF print formatting in English and Arabic.

### 2.2 Private Job Command Center (`/dashboard`)
* **Opportunity Inbox**: Multi-format import (manual, paste JD, URL) with duplicate detection and automatic alignment scoring.
* **11-Stage Application Pipeline**: Kanban and data table views (`Discovered` → `Applied` → `Interview` → `Offer`).
* **Application Studio**: Grounded generation of tailored cover letters, outreach pitches, and screening answers with unsupported claims warnings.
* **Interview Room**: STAR story suggestions, technical architecture talking points, and company research checklists.
* **Search Analytics**: Conversion rates, role lens ROI, and market skill demand heatmaps.
* **Admin CMS & Audit Logs**: Full CRUD for all profile entities with cryptographic audit logs.

## 3. Quickstart & Zero-Config Execution

CareerProof OS is self-contained with an embedded in-memory repository pre-loaded with rich seed data for Abdlrrahman Shibani. It runs locally without requiring external databases or paid AI API keys.

```bash
# 1. Clone repository
git clone https://github.com/abdlrrahman-shibani/careerproof-os.git
cd careerproof-os

# 2. Install dependencies
npm install

# 3. Run development server
npm run dev

# 4. Open in browser
http://localhost:3000        # English LTR
http://localhost:3000/ar     # Arabic RTL
http://localhost:3000/dashboard # Private Command Center
```

## 5. Technology Stack & Architecture

* **Framework**: Next.js 15+ App Router, React 19, TypeScript (Strict Mode)
* **Styling & Motion**: Tailwind CSS, Lucide Icons, Framer Motion (respecting `prefers-reduced-motion` and Emil Kowalski motion principles)
* **Persistence**: Universal repository adapter supporting embedded In-Memory / SQLite and Supabase PostgreSQL with RLS
* **AI Engine**: Multi-provider hub (Google Gemini, OpenAI GPT-4o, and local deterministic heuristic engine)
* **Testing**: Vitest, React Testing Library, JSDOM
